## Symmetry-normalized direct formulation

A later optional variant retains arbitrary architecture while applying Lemma 2 and exact decoder symmetries. For n>K, every output must read a non-output node. Therefore the earliest non-output node precedes every output and has only primary inputs. Relabel non-output nodes by their build order. A primary-input permutation puts the first helper support inside the first K inputs; pad its pins to exactly those K distinct inputs. Input XOR translation maps the earliest output pattern to zero, with the minterm output names translated correspondingly. Complement the first helper and adjust all readers if needed so its table bit zero is clear. These transformations preserve node count and acyclicity and allow output-to-output, output-to-helper and helper-to-helper dependencies. Thus each direct network has a representative satisfying these added constraints. This argument is written mathematics pending formalization; a checker refutes the resulting CNF, not this argument. Controls exercise positive K4,n5 and the already-refuted K3,n5 case.

## Multiple-helper collision reduction

`helper_bound.py` admits an arbitrary number H of non-output nodes. Apply Lemma 2, label the helpers in build order, normalize the earliest helper support by a primary-input permutation, and translate input patterns so the first output is minterm zero. The earliest helper precedes all outputs and reads inputs only. Other helpers have arbitrary K-pin LUTs selecting primary inputs, constants, earlier helpers, and minterm outputs whose rank precedes theirs. The pins and full truth tables of these helpers are encoded on every input pattern. A shared total order covers the outputs and the later helpers, with helper order enforced.

For output q, choose nonempty helper set S and raw primary-input set T. Let u=K-|S|-|T|. The collision class contains exactly x unequal to q that agree on T and on every helper in S. The output computes its minterm if and only if every point of that class is the minterm of an output it reads. Necessity gives class size at most u and every class point earlier than q, and each selected helper earlier than q. Sufficiency reads precisely those class outputs, selected helpers and raw inputs, then sets a single table row at q to one. Inputs padding with constant zero fills unused pins. This gives the same truth table as minterm q, with an acyclic build order. The decoder reconstructs these output tables and independently simulates the entire decoded graph.

For options reading only the input-only first helper, Lemma 3 places all free primary inputs within that helper support. For other helper sets the enumeration covers every raw-input subset, without a support restriction. Equality variables and guarded Sinz counters encode the collision cardinalities. Helpers may depend on previously built outputs, outputs may depend on previously built outputs, and no depth bound is imposed. This extends the one-helper argument; its mathematical bridge is written here and remains to be machine-checked. Controls compare with established direct results and plant the independently verified 130-node construction.

## Exhaustive helper-order cases

Helpers are already labeled in topological order and output zero is earliest among outputs. Exactly r helpers precede output zero, for a unique r in 1..H. Case r adds the two boundary order literals (omitting nonexistent boundaries). Their disjunction covers every normalized network. An accepted case refutation is conditional; a global bound requires every case and this coverage argument.

In case r=1, output zero has only the first input-only helper available and no earlier outputs. For n=K+2 its raw pins can be padded to K-1, leaving three free inputs, all inside that helper's support (otherwise it cannot isolate zero). Permute inputs within the K-position helper support so these three are the final three coordinates. This preserves the normalized support and zero pattern; all later helpers and outputs remain unrestricted. Since the first helper's table bit zero is clear, its other seven values on that face must be one. These seven units reduce this case without excluding any architecture. Positive and negative controls qualify the branch generator, including the known 130-node construction in case r=2.

## Ancestor retiming and the K=3 first-helper case

Before the earliest output, move every helper that is not its ancestor to after it. Relabel helper order and normalize the first helper support again. Thus the r helpers before output zero may all be required to be ancestors of it. In helper order, the last must be read by output zero; each other helper must either be read by output zero or by a higher-index helper among those r. These clauses preserve the union of the r cases, although they strengthen each case individually. Every lower-bound aggregation must cite this retiming argument.

For K=3,n=5,r=1 the first helper is zero exactly on the four patterns whose first three bits are zero. Those four minterms each have a one-LUT realization from that helper and inputs 3,4. Replace them by these equivalent realizations and move them before helper one. No other minterm can occur before helper one: if the first such output existed, it could read only primary inputs, helper zero, and these four minterms. At its non-quarter pattern, helper zero is one and all four minterms are zero. If its at-most-two read primary inputs contain a one among positions 0..2, at least four non-quarter patterns agree. If all its read positions among 0..2 are zero, varying the unread positions gives at least three non-quarter patterns agreeing with it. Reading fewer primaries (because quarter outputs consume pins) only increases this set. Thus no such output is a minterm. Helper one's output-pin candidates can therefore be restricted to those four paid minterms. The four forced output options and their early order do not add nodes. This finite combinatorial normalization remains a written bridge pending Lean formalization.

## Output-pin elimination and prefix isolation (stronger reduction)

Let output node q read helpers, primary inputs and u other output minterms. Its code at q has every read minterm zero. Any x unequal to q agreeing on the helper and primary signals must therefore equal one of those u read minterm patterns; otherwise it would present the same code to the original output LUT. For each read minterm p choose a primary coordinate at which p differs from q, and replace that minterm pin by that primary input. The target q now has a unique code: old non-colliding points still differ on a retained signal, and each old colliding point differs at its selected primary coordinate. Set the new LUT to the single row for q. Duplicate selected coordinates can be collapsed and unused pins padded. The node count and pin budget do not increase. Only output-to-output edges are removed; no helper edge is added. Doing this in original topological order preserves all node functions by induction, including helpers that read outputs. Thus every architecture has a representation with outputs reading only primary inputs and helpers.

Label helpers in original build order. Any output p read by helper h has an isolating signal set using only helpers earlier than h. The formula `isolation_bound.py` expresses exactly these prefix witnesses. All output options use a helper subset S and K-|S| primary inputs; padding by primary signals covers smaller supports. A true option implies the target differs from every other pattern agreeing on its primaries in at least one selected helper. A helper pin selecting output p requires at least one true prefix option for p. Every output requires some true option. The decoder chooses a true option with the smallest last helper index. Consequently every helper's selected output is built before it, so the decoded network is acyclic. No output-order variables or counters are needed. Helpers retain arbitrary K-input tables with primary, constant, earlier-helper and paid-minterm pins. The first helper reads primaries only, with its support normalized to the first K inputs, and helper table complements absorbed by readers as before.

This is a written completeness argument pending formal verification. Controls include the established one-helper SAT case, an unrestricted certified-UNSAT case, the 130-node cascade, and a forced output-to-helper-to-helper chain padded onto an independently verified decoder. Refutations certify the formula; the bridge above remains separately identified.

## Removing equivalent truth tables and pin orderings

`isolation_symmetric.py` retains prefix isolation and restricts the first helper's table to one representative per NPN class. A permutation and complementation of the first K primary inputs, plus complementation of the helper and corresponding consumer tables, achieves this without changing the decoder task: global input transformations permute the minterm output labels. All NPN orbits of K<=4 tables are enumerated; their disjoint union must cover every table with bit zero clear. This is a symmetry restriction, not a restriction to affine or any other preferred function class.

Later helpers use distinct signal pins in increasing signal order. A repeated signal or constant pin can be removed and the unused pin padded with a distinct primary input ignored by the truth table. Since n>=K, enough primary inputs exist; no node or new dependency is required. Permuting the table with the pins gives the same function. These transformations also preserve the prefix witnesses. The first-helper normalization is qualified by a one-helper SAT control and an unrestricted known UNSAT control before target runs. Every positive result is decoded and checked exhaustively as before. As with the base reduction, the completeness argument remains written mathematics pending formalization.
